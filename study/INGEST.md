## 每天用户上传一批试卷照片后
1. 先登记：来源试卷、年份（不明则null）、原卷印刷页码、题型、原题号、照片文件标识、内容指纹。每张照片的唯一ID用于查重，重复扫描不当新试卷。
2. 使用OCR提取可识别的文字，不自动修正模糊的题号、公式、正负号、机构线条。标注人工核实、推断、未核实三种证据状态。
3. 对照原图确认题干／附图／选项。若跨页，应连同续页一起检查。未经目视核对的源题只能进入待审核区。
4. 将题目映射到实际教材的小节（bookId、chapter、section），记录映射理由和可能的其他章节。跨章节知识点可以有多个链接，但原卷计数只保留一次原题ID。
5. 新题先经过“原题核实→答案校验→解析校验→题型适配→图示校验”。完整计算、证明、画图题保留原题型；客观变式只抽取可客观考察的独立知识点。
6. 用户的实际作答，及是否蒙的，应单独保存为用户私有学习记录；不能把“网页已发布”推定为“用户已经做过”。
7. 通过审核后将结构化条目纳入归档，并更新study/data/catalog.json。此版尚**没有**自动上传后一键入库的流程；当前OCR入口只能生成待审核草稿，正式发布仍需审核和更新仓库。

## 高频定义（严禁虚构）
- 目前显示：60个来自**两份**机械设计试卷判断题与选择题的“原卷考点出现记录”。
- “出现次数” = 本章当前样本中属于同一考点组的**不同原题ID数量**；重复照片、同一原题多次OCR、同一题跨章节归档都不能额外计数。
- “跨卷重复” = 至少出现于两份不同来源的试卷，不代表年份数。
- 没有足够独立真题样本时不使用“历年高频”“高概率押题”“必考”等标签。
- 机械原理目前以目录和教材条目为主，不计算真题高频。
- 后续样本增多，建议同时展示“出现原题数 / 独立试卷数 / 具年份样本数 / 最近一次出现时间”，并区分来源类型（真题、模拟题、教材自测、AI变式）。AI变式不计入原卷高频统计。

## 私人资料保护与版权
- public GitHub 仓库仅提交自行整理的索引、少量知识摘要和经许可的原创题；不公开上传整本教材、扫描页、原卷全文或私人答题记录。
- 每日图片与完整教材留在个人私有存储。浏览器内的掌握标记可手动JSON备份恢复，不表示跨设备同步。
- 如果需要自动同步成绩与每日照片，应引入登录和私有服务端存储，再决定账户与访问策略。
