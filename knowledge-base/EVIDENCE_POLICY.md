# 从试卷图片到知识点的证据规范

## 两类工作必须分开
- **原文转录**：只能把图像中看得清的字称为原文，不能靠常识补写题干、公式、选项或源题号。
- **知识点推断**：可根据不完整线索列多个候选知识点，并保存证据、备选解释和待核查状态。不能把推断结果伪装成原文。

## 推荐分析流程
1. 先读取本仓库的 `knowledge-base/index.json`，缩小到可能的知识点。
2. 再读取 `knowledge-base/mechanical-design/topics.json` 中对应ID；必要时查 formulas 与 confusions。
3. 逐个写出来源试卷、试题类型、印刷页码和题号；缺失一律填 null。
4. 分 A（明确），B（较可能），C（待补充）三级：B/C 保留为候选知识点，不自动混入正式题库。
5. 对照教材只能使用实际提供、已核对过的内容；目录给出候选范围，具体公式与术语须目视原页并登记双页码。
6. Quiz 应先展示来源映射及对答案的校验。错误答案、模糊公式、机械结构图不能自动发布。
7. 不在本 Public 仓库存储个人作答、访问令牌、整本受版权保护的教材正文、个人学习隐私信息。

## 数据可靠性
- 已归档的试卷知识点，来源于此前会话保存的映射，**未在本次仓库构建时重新逐页目视核对**。
- 已归档公式来自此前Quiz解析，**尚未用第十版教材全文逐项校核**。
- A/B/C级为证据质量标签，不等同真实测量的统计置信概率。
