## 检索命令

在仓库根目录运行。公开查询返回目录定位、原页核实摘要和自测题位置。私有逐页 OCR 草稿以阅读器页为单位，供查词和定位。公式、正负号、图号和上下标仍须看原图。

```sh
node scripts/knowledge-search.mjs --book mp3 "复合铰链"
node scripts/knowledge-search.mjs --book mp3 "例2.1"
node scripts/knowledge-search.mjs --book mp3 "自测1-7"
python3 scripts/scan-textbook.py --book mp3 reuse "private-textbook-data/机械原理学习指导第3版_逐页OCR检索.jsonl"
python3 scripts/scan-textbook.py --book mp3 search "瞬心" --chapter 2
python3 scripts/scan-textbook.py --book mp3 status
```

如要重新识别某页，将原始扫描件放在本地，运行 `python3 scripts/scan-textbook.py --book mp3 ocr "原始教材.pdf" --printed 58 --redo`。也可按章或指定 PDF 页处理。源文件须与登记指纹一致。省略 --redo 时跳过已入库页。重识别依赖 Poppler、Tesseract 和 chi_sim、eng 语言数据。
